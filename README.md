# Java Learning Notes

A numbered, run-in-order set of Java examples working up from "Hello World" to exceptions and input handling. Each folder is a self-contained topic with a small, commented program.

| 15 | Inheritance | 30 | Input (`System.in`, `BufferedReader`) |

## Running an example

Each file declares a `package` matching its folder, so compile and run from the repo root:

```bash
javac _30_Input/_30_1_Input_Code.java
java  _30_Input._30_1_Input_Code
```
